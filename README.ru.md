# AI Cycling Coach

Персональное веб-приложение для велосипедистов, которое объединяет учёт тренировок, статистику и AI-коучинг.

Проект написан на Python и FastAPI, а для работы с ИИ использует локальную языковую модель через Ollama. Основная цель — создать простую среду, в которой спортсмен может хранить данные тренировок, анализировать недавнюю активность и общаться с AI-тренером, учитывающим его профиль и историю тренировок.

## Текущие возможности

### Аутентификация

- Регистрация пользователя
- Вход и выход из аккаунта
- Аутентификация по паролю
- Cookie-based аутентификация с JWT

### Профиль спортсмена

Пользователь может создать и редактировать свой профиль спортсмена.

Профиль используется AI Coach как часть контекста при генерации ответов.

### Импорт тренировок

Данные тренировок можно импортировать из CSV-файлов.

Процесс импорта:

- проверяет загруженный файл;
- рассчитывает SHA-256 хэш;
- обнаруживает дубликаты тренировок;
- сохраняет загруженный файл;
- разбирает CSV-данные в объект тренировки;
- сохраняет тренировку в базе данных.

Можно импортировать несколько файлов одновременно. Каждый файл обрабатывается независимо, поэтому ошибка в одном файле не мешает импорту остальных.

### История тренировок

Пользователь может просматривать ранее импортированные тренировки.

Данные тренировок связаны с аутентифицированным пользователем, поэтому каждый пользователь имеет доступ только к собственным тренировкам.

### Статистика

Приложение формирует сводную статистику тренировок за выбранный период.

Статистика рассчитывается на основе сохранённых тренировок пользователя и может использоваться AI Coach как часть тренировочного контекста.

### AI Coach

Приложение включает AI-тренера, работающего через локальную LLM в Ollama.

Перед генерацией ответа AI Coach получает несколько видов контекста:

- профиль спортсмена;
- сводку тренировок за последние 7 дней;
- предыдущую историю чата;
- системный prompt;
- prompt пользователя;
- текущий prompt.

Благодаря этому AI Coach может давать рекомендации с учётом недавней тренировочной активности, а не воспринимать каждое сообщение как изолированный диалог.

Спортсмен может обсуждать с AI Coach тренировки, анализировать недавнюю активность, получать рекомендации и примерный тренировочный план.

История чата сохраняется в базе данных и доступна в последующих диалогах.

## Архитектура

Проект использует слоистую архитектуру:

```text
Router
   ↓
Service
   ↓
Repository
   ↓
Database
```

### Router

Роутеры отвечают за HTTP-слой:

- получение запросов;
- валидацию параметров запроса;
- работу с FastAPI dependencies;
- вызов сервисов;
- возврат HTTP-ответов и шаблонов.

Роутеры не обращаются к репозиториям напрямую.

### Service

Сервисы содержат прикладную и бизнес-логику.

Примеры:

- `UserService`
- `ProfileService`
- `WorkoutService`
- `StatisticsService`
- `ImportService`
- `CoachService`

Сервисы координируют операции между репозиториями и другими компонентами приложения.

Например, `ImportService` координирует валидацию файлов, сохранение файлов, разбор CSV и сохранение тренировок.

### Repository

Репозитории отвечают за операции с базой данных.

Примеры:

- `UserRepository`
- `ProfileRepository`
- `WorkoutRepository`
- `ChatRepository`

Репозитории инкапсулируют работу с SQLModel Session и запросами к базе данных.

### LLM Provider

Интеграция с LLM отделена за интерфейсом провайдера.

```text
CoachService
      ↓
LLMProvider
      ↓
OllamaProvider
      ↓
Ollama
```

Это делает основное приложение независимым от конкретной реализации LLM и позволяет добавить другого провайдера в будущем.

## Конфигурация

Приложение использует переменные окружения для конфигурации.

Создайте файл `.env` в корне проекта.

Как минимум приложению нужен секретный ключ для аутентификации:

```env
SECRET_KEY=your-secret-key
```

Секретный ключ загружается через конфигурацию приложения и используется для JWT-аутентификации.

Если вы хотите использовать AI Coach, Ollama также должен быть установлен и запущен локально.

## Установка

Клонируйте репозиторий:

```bash
git clone <repository-url>
cd mypet
```

Создайте и активируйте виртуальное окружение:

```bash
python -m venv .venv
source .venv/bin/activate
```

В Windows:

```bash
.venv\Scripts\activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

Создайте `.env` и настройте необходимые переменные окружения.

Убедитесь, что Ollama установлен и запущен локально.

## Запуск тестов

Запустите полный набор тестов:

```bash
pytest
```

Тесты покрывают основные сценарии приложения:

- аутентификацию;
- профили пользователей;
- операции с тренировками;
- статистику;
- AI Coach;
- импорт CSV;
- работу с файлами.

Тесты импорта также проверяют независимую обработку нескольких файлов, включая сценарий, где один файл завершается ошибкой, а остальные успешно импортируются.

## Импорт CSV

Файлы тренировок импортируются через интерфейс приложения.

Конвейер импорта построен так, чтобы каждый загруженный файл обрабатывался независимо:

```text
CSV-файл
   ↓
Валидация файла
   ↓
SHA-256 хэш
   ↓
Проверка дубликата
   ↓
Сохранение файла
   ↓
Разбор CSV
   ↓
Создание тренировки
   ↓
Commit в базу данных
```

Если файл не удаётся обработать, изменения в базе данных откатываются, а сохранённый файл удаляется при необходимости.

Успешно импортированный файл остаётся сохранённым локально.
